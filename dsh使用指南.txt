====================================================
 dsh 使用指南（Windows 原生版）
====================================================

【架构】
  204 服务器 (YOUR_LAB_IP，实验室): dsh 主实例，跑编程任务
        GUI: 127.0.0.1:3090
        → 185 反向隧道（常驻）: 185:8090→204GUI / 185:8022→204SSH
  Windows（家里，本机）: dsh 原生实例，跑个人任务
        GUI: 127.0.0.1:3080
        → 185 反向隧道（常驻）: 185:8091→WindowsGUI
  185 公网服务器: 纯中继，三个口只绑回环（安全，公网不可直达）

  手机/外部访问 = SSH 客户端做端口转发（安全路线），不走公网直连。

----------------------------------------------------
【⭐ 推荐: 带界面的 dsh 控制台（无需输命令）】
----------------------------------------------------
  双击  dsh-tunnel-console.py 旁的 “启动dsh控制台.bat”
  或运行:  python C:\Users\1\Desktop\dsh\dsh-tunnel-console.py

  功能:
     · 本机 dsh 卡片: 一键 启动 / 停止 本机 dsh web（pnpm dsh web）
     · 隧道卡片: 一键 启动 / 常驻 / 停止 三个隧道脚本
     · 更新卡片: 一键 运行 update-dsh（只有这一个按钮, 实时滚动构建日志）
     · 健康监控两行:
       - 本机端口行: 本机 3080/8090/8022/8091/3090 监听状态
         （8090/8022/8091 只有在家跑 dsh-tunnel.ps1 正向隧道才监听）
       - 185 隧道行: SSH 直查 185 上 8090/8022/8091 反向隧道是否在线
         （这才是“隧道配没配好”的真指标, 每 20 秒刷新一次）
     · 实时运行日志, 看清每一步
  依赖: 仅 Python 标准库（tkinter）, 不用装任何东西。

  ★ 注意: 控制台只是“遥控器”—— 隧道卡片真正干活还是各自的 .ps1,
    本机 dsh 卡片则直连仓库执行 pnpm dsh web。update-dsh 是一次性完整
    更新（git拉取→构建→重启）, 只有一个“运行更新”按钮, 没有停止语义。
    监控里显示的运行状态以端口/进程为准。仓库路径/端口/命令都在
    dsh-tunnel-console.py 顶部“配置区”修改（本机 dsh: DASH_REPO / DASH_PORT / DASH_CMD）。


----------------------------------------------------
【脚本位置】Windows 任意目录（别改名，-Stop 按文件名匹配）
----------------------------------------------------
  dsh-tunnel.ps1           在家正向隧道三连: 8090→204GUI / 8022→204SSH / 8091→WinGUI
  connect-lab-dsh.ps1      实验室局域网内连 204（纯隧道）
  dsh-tunnel-reverse.ps1   Windows→185 反向隧道（手机访问本机 dsh）

统一执行方式:
  powershell -ExecutionPolicy Bypass -File 脚本名.ps1 [参数]

----------------------------------------------------
【一次性设置（激活）】
----------------------------------------------------
1. 执行策略（二选一）:
   - 永久放开（推荐）: Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
   - 或每条命令都带 -ExecutionPolicy Bypass（本指南默认带）
2. 下载解锁: Unblock-File C:\Users\1\*.ps1（从浏览器下载才需要）
3. 密钥（Windows 的 ~/.ssh/id_ed25519，YOUR_USER-win）:
   - 已授权到 204(YOUR_USER 用户) 和 185(tunnel 用户)
   - 换机器时重新生成并授权:
     type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh YOUR_USER@YOUR_LAB_IP "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys"
     type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh tunnel@YOUR_PUBLIC_IP "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys"

----------------------------------------------------
【日常场景】
----------------------------------------------------
① 在家用 204（编程工作区，真实数据）:
     powershell -ExecutionPolicy Bypass -File C:\Users\1\dsh-tunnel.ps1 -Persist
     浏览器开 http://127.0.0.1:8090
② 在家同步/SSH 到 204:
     scp -P 8022 文件 YOUR_USER@YOUR_PUBLIC_IP:~/
     ssh -p 8022 YOUR_USER@YOUR_PUBLIC_IP
③ 在实验室连 204（局域网直连）:
     powershell -ExecutionPolicy Bypass -File C:\Users\1\connect-lab-dsh.ps1 -Persist
     浏览器开 http://127.0.0.1:3090
④ 本机 Windows dsh（个人任务）:
     浏览器直接开 http://127.0.0.1:3080
⑤ 手机访问（安全路线）:
     装 Termius / JuiceSSH → 登录 185(tunnel)
     → 本地端口转发 8090→127.0.0.1:8090（204）/ 8091→127.0.0.1:8091（Windows）
     → 手机浏览器开 127.0.0.1:8090 或 127.0.0.1:8091

----------------------------------------------------
【单独启停】
----------------------------------------------------
  dsh-tunnel.ps1           启/停/常驻: 直接跑 / -Stop / -Persist
  connect-lab-dsh.ps1      启/停/常驻: 直接跑 / -Stop / -Persist
  dsh-tunnel-reverse.ps1   启/停/常驻: 直接跑 / -Stop / -Persist
  -Stop 幂等，重复跑不报错。

----------------------------------------------------
【数据】
----------------------------------------------------
  204 和 Windows 各自积累自己的会话（不再双向同步）。
  共享配置（settings/凭据/预设）如需迁移: 从 204 打包
    scp -P 8022 YOUR_USER@YOUR_PUBLIC_IP:~/.dsh 相关文件 到本机
  （会话绑定 workspace 路径，跨机器只读、不可续聊，属正常）

----------------------------------------------------
【注意事项】
----------------------------------------------------
1. 204 和 Windows 两条反向隧道都只绑 185 回环（安全默认）；
   不要为"手机直连"开 GatewayPorts 公网暴露——无鉴权 GUI 暴露公网=远程代码执行入口。
2. ps1 脚本别改名、同名别放两份（-Stop 按文件名/进程匹配）。
3. 185 上端口分配: 8090=204GUI / 8022=204SSH / 8091=WindowsGUI，改端口要同步改脚本。
4. 隧道断线自动重连（-Persist / 204 侧脚本自带循环）。
