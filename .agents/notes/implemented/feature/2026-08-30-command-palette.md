# 全局命令面板 Ctrl+K + 用量页纵向滚动

- Status: implemented
- Date: 2026-08-30

## 背景

执行顺序第 ④ 步(P3 收尾)。愿景 §八.1: 全局命令面板, 搜索页面/操作/隧道, 键盘直达
(OTP 式高效操作)。同批: 用户反馈用量页加趋势卡后三栏被压扁, 要求纵向滚动。

## 决策

1. **落位与触发**: QShortcut Ctrl+K 挂主窗口; 面板用 `Qt.Popup` 无边框 QDialog——
   点外自动关闭 + 自动抢焦点, 是 ComboBox 弹层的成熟范式, 不自己写焦点管理。
2. **命令现组装不建注册表**: 打开时从 NAV_ITEMS(16 页) + 当前部署清单 + 固定动作
   (立即刷新)拼装 —— 页面/部署增删免维护。run 为零参闭包, **accept 之后才执行**
   (弹窗生命周期内不改 UI 树, 避免页面重建与 popup 析构竞态)。
3. **过滤为纯函数**: `rank_commands(cmds, query)` 大小写不敏感子串匹配 title(含
   meta), 前缀命中排前; 不引拼音库(零依赖), 中文按子串即可。单测覆盖。
4. **列表复用 ModernList**: title/meta 行渲染与全应用一致(含自绘选中块), 零新样式。
5. **用量页滚动**: 三栏 three_split 给 `setMinimumHeight(430)` —— 视口剩余不足时
   QScrollArea 出纵向滚动条, 不再压扁三栏(趋势卡加入后的直接后果); 大屏不受影响
   (splitter 仍可拉伸)。

## 拒绝的替代方案

- **注册表式命令中心(静态声明所有命令)**: 页面/部署是动态的, 双份事实源必然漂移;
  打开时现组装 + 闭包捕获最简。
- **QListView+自绘代理**: ModernList 已有同款视觉, 重复造轮子。
- **面板常驻隐藏**: 常驻控件参与布局/焦点链, 按需创建更干净(构造成本可忽略)。
- **用量页拆掉滚动区改固定布局**: 视口高度不可控, 三栏最低高度 + 滚动是既有范式。

## 影响

- `ui/palette.py`(新), `dsh-console-aio.py`(快捷键 + _open_palette),
  `ui/pages_usage.py`(三栏最低高度), `tests/test_palette.py`(4 组)。
- 357 例纯单元全过; 面板端到端离屏冒烟(18 条命令组装/过滤/选中) + 截图确认。
- 已知边界: 命令不含"隧道启停"等写操作(误触代价高, 面板定位是导航/查询直达);
  拼音检索未做(需要引依赖或拼音表, 当前中文子串够用)。
