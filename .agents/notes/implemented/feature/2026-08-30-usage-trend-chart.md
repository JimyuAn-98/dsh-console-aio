# 用量趋势图表（自绘堆叠柱状图, 模型用量页趋势卡）

- Status: implemented
- Date: 2026-08-30

## 背景

ROADMAP「下一步执行顺序」第 ③ 步(P3 收尾项)。用量页已有按模型/按天两个只读列表,
但"趋势"不可见——某天爆量、哪个模型在涨, 要自己扫列表。愿景 §八.4: 用量按模型/
日期的图表(QtCharts 或自绘)。

## 决策

1. **自绘不引 QtCharts**: 零新依赖控包体(onefile 体积敏感), 且配色/网格/文字完全
   走 TOKENS 与现有主题同源——QtCharts 的暗色定制反而更绕。控件 `ui/chart.py`
   StackedBarChart: set_series(days, models) + paintEvent 自绘 + mouseMoveEvent
   悬停 QToolTip 当日明细。
2. **堆叠值 = 输入 + 输出, 不含缓存命中**: cache read 动辄是输入的几十倍, 计入会
   把真实工作量曲线压成一条线; 缓存数在按天列表/悬停明细里另有出口。core 的
   `usage_stats` 新增 `days_models` 维度(天×模型, 与 days 同源累加, 一次扫描两份
   产物, 向后兼容)。
3. **窗口切换不重扫**: 7/14/30 天只对最近一次统计结果重排(扫描要解压全部会话,
   秒级开销不该为切窗口重复付)。模型按窗口内总量取前 8, 其余并入「其他」,
   防图例爆炸。
4. **模型配色**: 固定 8 色板(首色=accent)按堆叠序循环, 不做动态调色——稳定色帮
   助用户跨天数识别同一模型。
5. **落位**: 用量页顶部信息条之下、三栏之上, 竖排卡片; 高度 190px 起步可被页面
   滚动容纳。

## 拒绝的替代方案

- **QtCharts**: PySide6-Addons 依赖入包 + 暗色主题定制繁琐 + 交互定制受限。
- **堆叠含缓存命中**: 大数吃趋势, 图表失去信息量。
- **图表进"按天"栏或弹窗**: 页面顶部横幅位置信息密度最高, 且不挤压既有三栏。
- **切换窗口触发重扫**: 为改个可见范围解压全部会话, 纯浪费。

## 影响

- `ui/chart.py`(新), `ui/pages_usage.py`(趋势卡 + _update_chart), `core/data.py`
  (usage_stats 增 days_models)。
- 353 例纯单元全过; 真实数据(59 会话/6 模型/11 天)离屏渲染验证, 截图确认。
- 已知边界: 远程部署统计不支持(沿用原提示), 趋势卡显示占位文案。
