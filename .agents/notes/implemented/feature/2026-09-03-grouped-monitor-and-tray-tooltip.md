# 右侧监控栏按拓扑卡片分组与托盘悬浮 Tooltip 丰富化

- Status: implemented
- Date: 2026-09-03
- Related: `ui/monitor.py`, `dsh-console-aio.py`, `tests/test_gui_ui.py`

## 背景

在动态 SSH 隧道向导和方案拓扑管理上线后，隧道管理体验已高度模块化（每条隧道呈现为一张独立卡片）。但周边配套界面存在 3 处割裂：
1. **左侧导航栏名称不一致**：显示为「隧道」，与页面标题「SSH 隧道管理」不齐；
2. **右侧监控栏堆叠割裂**：右栏将所有端口扁平罗列在「本机端口」与「公网中转 反向隧道」两组内，无法分辨各端口归属于哪张隧道卡片；
3. **系统托盘悬浮信息简陋**：鼠标悬停任务栏图标仅显示「隧道: 已停止」，缺乏方案名称与具体隧道在线明细。

## 决策与设计

1. **导航项对齐（`dsh-console-aio.py`）**：
   - 将 `NAV_ITEMS` 中的 `('隧道', 'tunnels')` 规范为 `('SSH隧道管理', 'tunnels')`，保持路由 key 不变。
2. **右侧监控栏按卡片分组（`ui/monitor.py::RightBar`）**：
   - 顶部固定呈现「`[本机]服务端口`」（`L3080` GUI）；
   - 后续分组**严格复用当前方案中的各隧道卡片名称**（带 `(正向)` / `(反向)` 标识），分类下列出属于该卡片的全部映射端口；
   - 单元格内部 Key 仍维持 `L<port>` / `R<port>` 规范，底层 TCP 探活与 `set_state` 刷新机制 100% 保持原有高性能；
   - 收起为窄条模式时自动隐去分组标题，保证折叠态整洁。
3. **任务栏托盘 Tooltip 丰富化（`dsh-console-aio.py::_apply_monitor`）**：
   - 悬浮展示当前生效方案名称及隧道总览：`DSH 控制台 · [方案名] (N/M 隧道在线)`；
   - 逐行展示 `dsh web`（端口 + 延迟）及各个隧道卡片的在线状态与映射端口列表（例如 `● cn2服务器正向隧道: 在线 (:8090, :8022)` / `○ 本机反向隧道: 已停止 (公网:8091)`）；
   - 格式控制在紧凑多行内，杜绝 Windows Tooltip 字符溢出截断。

## 影响与验证

- 主界面、卡片流、右侧栏与系统托盘完全对齐，概念统一、信息层级清晰；
- 在 `tests/test_gui_ui.py` 中补充 `test_right_bar_grouped_by_tunnel_cards` 与 `test_tray_tooltip_rich_content`；
- 全量 511 个单元测试与 GUI 测试全部 100% 通过，命令行离屏启动冒烟正常。
