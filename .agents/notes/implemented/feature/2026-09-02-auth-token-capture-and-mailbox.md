# Agent Note: dsh 0.1.2+ 鉴权 Token 静默捕获与 SSH 信箱跨端免密访问

- **日期**: 2026-09-02
- **状态**: implemented
- **分类**: feature

---

## 背景与问题

dsh 从 0.1.2 版本开始引入了随机 32 字节一次性启动 Token 鉴权机制。
在“家 - 办公室 - 实验室”三地远程隧道拓扑中，虽然本机启动会通过 dsh 自动唤起本机浏览器，但从家里远程通过隧道访问办公室/实验室的映射端口时，家里的浏览器缺少 Token 和签名 Cookie，会直接收到 401 拦截。

---

## 决策与架构设计

1. **放弃公网第三方服务中转方案**：
   - 不在公网 VPS 上部署任何 Node/Python 服务或开对外 HTTP 端口，避免外部依赖和运维负担；
   - 纯粹复用已有的 SSH 管道，将公网 VPS 当作安全的「状态信箱」。
2. **反向隧道节点静默捕获与推送**：
   - 办公室与实验室节点启动 dsh 时，后台从 stdout 提取 32 字节 Token；
   - 建立反向 SSH 隧道时，顺带在公网 VPS 执行一条原子指令 `echo '<token>' > ~/.dsh_runtime/<node>.token && chmod 600 ~/.dsh_runtime/<node>.token`。
3. **家里客户端节点拉取与免密链接复制**：
   - 家里拉取隧道后，自动读取公网信箱的 Token，并组装 `http://127.0.0.1:<LOCAL_PORT>/?token=<TOKEN>`；
   - 在总览页与部署管理页提供「复制免密链接」纯文本按钮；
   - 用户在家里初次复制到浏览器打开即可换取 30 天签名 Cookie，后续 30 天免鉴权访问。
4. **极简 UI 原则**：
   - 完全不做任何冗余的“打开 Web 界面”按钮，保持控制台界面极度清爽。
