# 项目文档结构整理与收敛方案（2026-09-01）

> 归档计划编号：`20260901-文档结构整理与历史归档-v1`
> 状态：已批准并执行中

整理当前项目中内容重复、散落和历史阶段性文档，确立单一权威来源（Single Source of Truth），清理无关研究目录，保持工程文档清晰清爽。

## 目标与收敛原则

1. **单一权威来源**：每个领域（架构、路线、测试、问题、Agent 铁律）只有一份唯一权威文档，其他文档只引用不重复拷贝。
2. **活跃与归档严格隔离**：`docs/` 根目录下只保留当前活跃的权威文档；所有已完成的迁移规范、历史方案草稿、单项 issue 报告移入 `docs/archive/`。
3. **计划文件规范沉淀**：每次实施方案与计划沉淀至 `docs/plans/YYYYMMDD-主题-vX.md`。
4. **清理无关调研资产**：删除 `_research/dsh-desktop`（消除 50+ 个外部文档对全局搜索的干扰），保留 `_research/dsh-market`。
